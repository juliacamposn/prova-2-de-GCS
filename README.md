# GCS - Trabalho - MinhaEstanteVirtual

Este respositório, de um projeto ficcional, tem, como atual objetivo o Trabalho Prático da disciplina de GCS - Gerência de Configuração de Software.

Inicialmente teve como objetivo a prova parcial 2 da mesma disciplina. 

"O projeto trata-se de uma aplicação web simples para catalogar e organizar coleções de livros, chama-se MinhaEstanteVirtual" - Júlia Campos.
